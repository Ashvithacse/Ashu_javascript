# Travel Recommendation Web Application

A simple travel recommendation website built with HTML, CSS, and JavaScript.

## Features
- Responsive navigation bar
- Search functionality for destinations
- Filter buttons for beaches, temples, and countries
- Travel recommendation cards with images
- About Us section
- Contact Us form
- Mobile-friendly layout

## Project Structure

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Open the project folder.
2. Double-click `index.html` in a browser, or
3. Run a local server in the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
